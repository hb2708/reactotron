# Reactotron for VS Code & Cursor

Drop-in Reactotron desktop inspector running inside VS Code / Cursor on top of `reactotron-core-ui` and `apps/reactotron-app` renderer components, backed by an isolated `worker_threads` WebSocket server.

## Install from VSIX

```bash
code --install-extension reactotron-vscode-0.1.0.vsix
```

Open via Command Palette (`Cmd+Shift+P` -> **Reactotron: Open Inspector**) or click the **Reactotron** status bar item.
